## 验收范围

本次验收使用 `t5-live-v1` 七条合成黄金 Case，读取 T4 已发布到真实 MongoDB、Milvus 和
MinIO 的 2 个 Document、5 个 Chunk 与 1 个 Image。数据均为模拟/CC0 展示资料，不代表真实
Fab 数据或线上指标。

真实链路为：

```text
JWT ActorScope + 结构化约束
  -> Milvus 前置 approval/lifecycle/effective/ACL/工艺字段过滤
  -> 本地 BGE-M3 Query Dense + Sparse
  -> 条件式 Luna HyDE Dense
  -> Python RRF 融合
  -> MongoDB Chunk 正文回填与二次权限校验
  -> qwen3-rerank
  -> 最低相关度 + 断崖检测 + 受保护证据
  -> image_text 关联 MinIO 真实图片
  -> MongoDB RetrievalTrace
```

## 在线基线

| 变体 | Recall@5 | MRR | 无证据识别 | 平均耗时 |
| --- | ---: | ---: | ---: | ---: |
| Dense | 0.8571 | 0.5714 | 0.5000 | 584.34 ms |
| Dense + Sparse | 0.8571 | 0.5714 | 0.5000 | 658.72 ms |
| Dense + Sparse + Reranker | 1.0000 | 0.7143 | 1.0000 | 954.21 ms |
| Dense + Sparse + HyDE + Reranker | 1.0000 | 0.7143 | 1.0000 | 5314.08 ms |

结论：真实 Qwen Reranker 在当前小语料上消除了越域问题的误证据，并提高了排序；强制 HyDE
没有带来额外命中增益，却增加约 4.36 秒平均延迟。因此运行时仅对原因、根因、异常和排查类问题
条件启用 HyDE，并保留失败时回退到原始 Dense/Sparse 的能力。该结论只适用于当前冻结数据集，
扩充 SOP、Recipe、Case 后必须重新评估。

## 权限与图片验收

- Milvus 活动别名指向 `semikb_chunks_v2`，5 条向量均为 `published`。
- API 真实检索返回 HTTP 200，Trace 能按当前用户读取。
- 文本查询命中 `T4-CASE-ETCH-03-R1-IMAGE-001`，关联真实 PNG。
- MinIO 五分钟预签名 URL 返回 HTTP 200、`image/png`、2436 bytes。
- `P-BETA` 用户访问 `P-ALPHA` 图片返回 HTTP 403。
- Trace 只保存稳定 `image_id`，不保存预签名 URL。
