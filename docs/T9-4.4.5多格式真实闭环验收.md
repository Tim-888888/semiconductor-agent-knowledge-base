## 2. 黄金文件

`data/t9445_golden/manifest.json` 冻结九类可公开展示的 CC0 合成验收文件：

| 格式 | Parser | 主要验收内容 |
| --- | --- | --- |
| Markdown | `markdown-structured-v1` | 标题、列表、表格、代码块和控制令牌 |
| TXT | `text-structured-v1` | 编码、段落和 RF Match 检查项 |
| HTML | `html-structured-v1` | 正文净化、标题和表格；导航/脚本噪声不得入库 |
| PDF | `pdf-mineru-v1` | 两页内容、表格、内嵌晶圆图、页码和关键放行语义 |
| DOCX | `docx-structured-v1` | 标题/段落顺序、列表、表格、图片和图注 |
| XLSX | `xlsx-structured-v1` | Sheet、表头、单位、合并单元格和表格区域 |
| CSV | `csv-structured-v1` | 分隔符、列语义和表格 Chunk |
| PPTX | `pptx-structured-v1` | Slide、文本框、表格、图片和页面位置 |
| PNG | `image-vlm-v1` | 原图、`qwen3.7-plus` 图注/OCR/检测摘要和 `image_text` |

黄金文件由 `scripts/generate_t9445_golden_files.py` 确定性生成，清单保存 SHA-256、媒体类型、文档 ID、
Parser、最低 Chunk/图片/表格数量、必需/禁止语义和检索问题。首轮 PDF 将关键 `leak check` 句放在
页面底部图片之后，真实 MinerU 正确提取了 4 个 Chunk、2 张图片和 1 张表，但遗漏该句。修正版将
关键句移到第一页稳定文本区，并使用 `T9445-PDF-ESCALATE-42` 和新文档 ID，避免降低质量门禁或与
已发布 R1 哈希冲突。
