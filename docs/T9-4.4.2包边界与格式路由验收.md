# T9-4.4.2 包边界与格式路由验收

## 1. 结论

T9-4.4.2 已建立独立顶层 Python 包 `semikb_ingest`，实现冻结输出模型、九格式显式注册表、

## 3. 公开契约

`semikb_ingest.models` 将 `semikb-ingest-v1` JSON Schema 落实为严格 Pydantic 模型：

```text
IngestDispatcher.parse(...)
  -> ParsedDocument
       -> ChunkDraft[]
       -> ImageAssetDraft[]
       -> TableAssetDraft[]
       -> ParseProvenance
       -> ParseWarning[]
       -> ParseMetrics
```

- 模型禁止未知字段，不接收 `document_id`、审批、版本、权限、Fab、Tool、Recipe 或索引字段。
- Chunk、图片和表格 ID 必须唯一；父子、图片和表格引用必须指向同一输出中真实存在的对象。
- `BinaryPayload.handle` 由 `ProcessPayloadStore` 生成，只能在当前 Worker 进程中读取消费；读取和弹出时
  重新核对大小与 SHA-256，不能被当成 MinIO 对象路径持久化。
- `IngestDispatcher` 计算输入 SHA-256，选择完全匹配的 Parser，并校验输出格式、Parser Provenance
  和源 Hash；不一致时返回 `INGEST_CONTRACT_VIOLATION`。

运行时样例输出已通过 4.4.1 冻结的 Draft 2020-12 JSON Schema 验证。

## 4. 格式识别流程

```text
filename + declared MIME + bytes
  -> 文件大小门禁
  -> 规范化扩展名和 MIME
  -> 检测 PDF / PNG / JPEG / ZIP Magic Bytes
  -> ZIP 时只读中央目录
       -> Entry 数量、展开大小、压缩比
       -> 路径穿越、Windows Drive Path、重复路径、加密标志
       -> [Content_Types].xml + word/xl/ppt 必需成员
  -> 汇总全部可用信号
       -> 唯一且兼容：返回 ResolvedRoute
       -> 信号冲突：INGEST_FILE_TYPE_MISMATCH
       -> Office 无效：INGEST_INVALID_OFFICE_CONTAINER
       -> 可疑压缩包：INGEST_ZIP_BOMB_SUSPECTED
       -> 未支持/无法唯一判断：INGEST_UNSUPPORTED_FORMAT
```

有扩展名时，扩展名用于选取候选规则，但不能覆盖相冲突的 MIME、Magic Bytes 或 Office 容器成员。
无扩展名时，仅在 MIME、Magic Bytes 或 OOXML 成员能够唯一确定格式时路由；`text/plain` 可能代表
Markdown、TXT 或 CSV，缺少扩展名时明确拒绝，不进行猜测。

## 5. 九格式显式路由

| 格式 | Parser ID | Provider | 识别要点 |
| --- | --- | --- | --- |
| Markdown | `markdown-structured-v1` | `builtin` | `.md/.markdown` + 文本 MIME |
| TXT | `text-structured-v1` | `builtin` | `.txt` + `text/plain` |
| HTML | `html-structured-v1` | `local-html` | `.html/.htm` + `text/html` |
| PDF | `pdf-mineru-v1` | `mineru` | `.pdf` + `application/pdf` + `%PDF-` |
| DOCX | `docx-structured-v1` | `local-docx` | ZIP + DOCX MIME + `word/document.xml` |
| XLSX | `xlsx-structured-v1` | `local-xlsx` | ZIP + XLSX MIME + `xl/workbook.xml` |
| CSV | `csv-structured-v1` | `builtin-csv` | `.csv` + CSV/文本 MIME |
| PPTX | `pptx-structured-v1` | `local-pptx` | ZIP + PPTX MIME + `ppt/presentation.xml` |
| 图片 | `image-vlm-v1` | `qwen-vl` | PNG/JPEG 扩展名、MIME 与各自 Magic Bytes |

只有 PDF 路由声明 `provider=mineru`。图片只允许格式内声明的
`ocr_only_when_configured`，其余格式没有回退；Parser 或 Provider 未显式注册时使用
`INGEST_PARSER_NOT_CONFIGURED` 失败。
