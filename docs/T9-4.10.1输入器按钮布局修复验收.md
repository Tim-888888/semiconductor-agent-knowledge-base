# T9-4.10.1 输入器按钮布局修复验收

## 1. 结论

2026-08-23，输入框展开/收起按钮与发送按钮在部分浏览器尺寸和缩放比例下重叠的问题已修复。
本阶段只调整工程师工作台输入器的前端结构和样式，不改变消息提交、线程状态、API、Agent 路由或存储。

## 2. 根因与修复

T9-4.10 将展开按钮定位在输入器右上方，将发送按钮定位在右下方。收起状态只有 `74px` 高，两个按钮
同时占用同一条右侧垂直轨道，在浏览器缩放或可用高度变化后会发生矩形交叠。

修复后两个按钮由同一个 `.composer-actions` 容器管理：

1. 操作区固定在输入器右下角，并使用横向 `flex` 布局。
2. 两个按钮均为 `32 x 32px`，固定间距为 `6px`。
3. textarea 右侧内边距调整为 `86px`，文本不会进入操作区。
4. 收起和展开状态共用同一套按钮定位，不再依赖输入框高度。
5. 发送按钮补充稳定测试标识和 `aria-label`，展开按钮原有可访问属性保持不变。

## 4. 浏览器验收

### 4.1 桌面 `1440 x 900`

- 收起状态 textarea 高 `74px`，展开状态高 `324px`。
- 两个按钮均为 `32 x 32px`，横向间距 `6px`，收起和展开状态的矩形交叠均为 `false`。
