# T9-4 端到端验收计划

## 1. 目标与边界

T9-4 是一期部署的最终验收阶段。它既包含 SSE 流式对话等必要开发，也包含从用户操作到存储恢复的
完整验证。T9-4 未完成前，不得把 T9 或当前 ECS 标记为完整演示环境。

本阶段不新增基础设施服务。SSE 使用 FastAPI/Starlette、现有 LangGraph 与 LLM 网关、浏览器原生
`fetch + ReadableStream` 和 Nginx 实现；容量脚本继续使用项目现有 Python/httpx、Docker 和测试工具。
如后续提出 Prometheus、Grafana、Locust、k6 或 ACR 等新组件，应先说明用途、成本和部署影响并获得批准。

测试期保留三项已批准例外：HTTP、MongoDB 单机、SSH 22 对公网和密码登录。它们不阻塞面试 Demo
验收，但必须在最终报告中列为正式发布阻塞项，不能描述为生产安全已完成。

## 3. SSE 事件契约

新增路由建议为：

```text
POST /api/v1/threads/{thread_id}/messages/stream
Accept: text/event-stream
Content-Type: application/json
Authorization: Bearer <token>
```

事件顺序和职责：

| 事件 | 作用 | 可见内容 |
| --- | --- | --- |
| `accepted` | 确认服务端接收请求 | `request_id`、`thread_id`、时间戳 |
| `stage` | 告知当前真实处理阶段 | 约束分析、知识检索、重排序、生成、校验、持久化 |
| `evidence` | 检索完成后给出受权限过滤的证据摘要 | 证据 ID、标题、来源类型和数量，不含隐藏内容 |
| `answer_delta` | 增量传输 Provider 返回的真实答案 Token | 仅用户可见答案文本 |
| `heartbeat` | 长步骤期间维持连接和反馈 | 时间戳，不携带业务数据 |
| `completed` | 返回规范化最终结果 | 与非流式接口一致的完整线程响应和 Trace ID |
| `error` | 返回可展示错误并结束本次流 | 稳定错误码、可读消息、是否可重试，不含内部异常和密钥 |

关键实现规则：

- 使用 POST + `fetch`，因为消息包含 JSON 请求体和 Bearer Token；不使用原生 `EventSource`。
- 前端通过流式 `TextDecoder` 处理跨网络分片的 UTF-8 和不完整 SSE 行，不能假设一次 `read()` 就是一条事件。
- 使用 `AbortController` 支持停止生成；页面关闭、切换线程和网络断开时释放读取器。
- `request_id` 作为幂等键。断连后重新读取线程，以 MongoDB 中的规范状态对账，不能盲目再次追加消息。
- 只在完整答案通过现有验证后写入最终助手消息。失败或取消不得把半截答案标记为完成。
- 保留现有非流式 POST 接口，不在同一次改动中破坏 T6/T8 和既有客户端。
- Nginx 对 SSE 路由设置 `proxy_buffering off`、`proxy_cache off`、较长 `proxy_read_timeout`，并返回
  `X-Accel-Buffering: no`；用 `curl -N` 验证公网链路没有重新缓冲。
- 不发送 Chain-of-Thought、内部 Prompt、工具密钥、完整异常堆栈或未通过权限过滤的证据。

## 4. 流式体验验收

- 点击发送后立即显示用户消息和助手占位，不再等待完整请求返回才更新页面。
- 非过载情况下，SSE 建连后 1 秒内显示 `accepted` 或首个 `stage`。
- 任意超过 10 秒的安静窗口由 `heartbeat` 填充；用户始终知道请求仍在执行。
- 答案区域随真实 `answer_delta` 增长，布局尺寸稳定，不因长文本、引用或按钮状态发生跳动和重叠。
- “停止生成”可操作；取消、超时、断网和服务器错误均显示明确状态，重新进入线程后与服务端状态一致。
- `completed` 后证据抽屉、图片、Trace 和后续追问立即可用；刷新页面后内容不丢失、不重复。
- 当前完成结果的最终授权证据包含一张或多张图片时，自动选择并显示最终证据顺序中的第一张；只预加载
  第一张，多图资产列表仍可手动切换，用户手动选择后不得被同一结果重复覆盖。
- 新的检索结果不含图片时清除旧预览；无权、过期或短时链接加载失败时不得展示旧图或绕过资产访问 API，
  应保留可诊断状态且不影响文本答案。
- 桌面和 390 x 844 移动视口完成真实点击与截图；浏览器控制台没有 error/warning。
