# 运行时兼容矩阵

| 层 | 一期基线 | 备注 |
| --- | --- | --- |
| Python | 3.12 | 后端和 Worker 使用同一镜像 |
| FastAPI | `>=0.115,<1` | REST API |
| LangGraph | `>=0.2,<2` | Demo `InMemorySaver`；生产切 Mongo Checkpointer |
| MongoDB Driver | PyMongo `>=4.10,<5` | 单机开发，生产建议副本集 |
| Milvus Client | PyMilvus `>=2.5,<3` | 需以已部署 Milvus 镜像版本复核 Sparse/HNSW 能力 |
| MinIO Client | `>=7.2,<8` | 私有 Bucket 与预签名对象访问 |
| Redis / Celery | Redis 7.4 / Celery 5.6 | broker/result，不作为业务状态真相 |
| Node | 22 LTS | React/Vite 构建镜像 |
| Nginx | 1.27 Alpine | 静态前端和 `/api/` 反向代理 |

在获得 CentOS 的 `docker ps`（镜像标签、端口、网络）之前，不锁定 Milvus、MongoDB、MinIO
服务镜像版本，也不建议把它们重复放入应用 Compose。届时需要对实际版本执行连接预检、Sparse
Vector Collection 创建与 HNSW 索引演练，再更新本矩阵。
