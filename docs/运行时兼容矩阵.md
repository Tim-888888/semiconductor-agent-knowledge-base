# 运行时兼容矩阵

| 层 | 一期基线 | 备注 |
| --- | --- | --- |
| Python | 3.12 | 后端和 Worker 使用同一镜像 |
| FastAPI | `>=0.115,<1` | REST API |
| LangGraph | 1.2.10 | Demo 使用 `InMemorySaver`；真实模式已验收 Mongo Checkpointer/Store |
| LangGraph MongoDB | Checkpoint 0.4.0 / Store 0.3.0 | `checkpoints`、`checkpoint_writes`、`long_term_memories`；PyMongo 4.16.0 |
| MongoDB Driver | PyMongo `>=4.10,<5` | 单机开发，生产建议副本集 |
| Milvus Client | PyMilvus `>=2.5,<3` | 需以已部署 Milvus 镜像版本复核 Sparse/HNSW 能力 |
| MinIO Client | `>=7.2,<8` | 私有 Bucket 与预签名对象访问 |
| Embedding | 在线 `qwen3.7-text-embedding` + `lexical-hash-v1` | 1024 维 L2 Dense；Sparse 为 CPU 词法哈希，无 Torch/GPU/本地权重依赖 |
| Reranker | 在线 `qwen3-rerank` | RRF 后精排；API 异常时按 Trace 记录并降级，不加载本地模型 |
| Redis / Celery | Redis 7.4.10 (`redis:7.4-alpine`) / Celery 5.6 | Docker 26.1.4、Compose 2.27.1 已验收；broker/result，不作为业务状态真相 |
| Node | 22 LTS | React/Vite 构建镜像 |
| Nginx | 1.27 Alpine | 静态前端和 `/api/` 反向代理 |

在获得 CentOS 的 `docker ps`（镜像标签、端口、网络）之前，不锁定 Milvus、MongoDB、MinIO
服务镜像版本，也不建议把它们重复放入应用 Compose。届时需要对实际版本执行连接预检、Sparse
Vector Collection 创建与 HNSW 索引演练，再更新本矩阵。

当前真实服务已完成 `semikb_chunks_v3` 的 Dense HNSW、Sparse Inverted Index、`lifecycle`
字段读写及 `semikb_chunks_active` Alias 验收；`v2` 作为迁移回滚投影保留。该结果证明当前连接目标
支持项目能力，但不替代 T9 对服务镜像标签和阿里云部署组合的最终冻结。

T6 已在当前 MongoDB 单机实例验证 14 个同线程 Checkpoint 的暂停/跨服务实例恢复。该结果只证明
一期功能持久化可运行；阿里云生产仍需升级副本集、备份恢复、最小权限和连接池/故障转移验收。
