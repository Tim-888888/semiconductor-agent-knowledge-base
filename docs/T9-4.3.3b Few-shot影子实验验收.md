# T9-4.3.3b Few-shot 影子实验验收

## 1. 结论与边界

2026-08-14，T9-4.3.3b 已完成 A/B/C/D 四组离线影子实验实现、同冻结集在线 Provider 对照、
质量与安全门禁、Token/延迟/调用/参考成本统计、本地回归和目标 ECS 的 B 默认臂复验。

本轮没有产生可上线的新候选：

- C 固定 Few-shot 虽减少严格失败并改善任务结构，但意图卡 Macro-F1 相对 B 回退，未通过门禁。
- D 动态 Few-shot 相对 B 的总体指标较好，但多任务精确匹配和关键混淆对准确率均只与 C 持平，未满足
  “两项都严格优于 C”的动态上线门禁；同时增加在线 Embedding 调用且 P95 时延更高。
- 线上默认继续保持 B，即全部活动意图卡、无 Few-shot、无意图示例 Embedding。C/D 均未进入生产路由。

本结论不包含自然直接回答、组合执行或完整业务浏览器闭环。`T9-4.3.3c~d`、`T9-4.3.4`、T9-4
和 T9 仍未完成。
