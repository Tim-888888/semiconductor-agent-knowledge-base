# 样例数据与黄金集

`data/fixtures/demo_corpus.json` 和 `data/assets/` 完全由项目构造，不包含真实 Fab、客户、
Recipe 参数或生产数据。所有文档逐条显式记录 synthetic source URI、CC0-1.0、版本、审批、
有效期、`access_scope_key`、Fab/Product/Tool/Chamber 范围。

## 当前数据

| 类型 | 内容与用途 |
| --- | --- |
| SOP R1/R2 | 历史/现行版本过滤和 supersedes 版本链 |
| Recipe V2.2/V2.3 | 独立 Recipe 历史/现行版本、虚构参数窗口和审批约束 |
| Case 与 FDC | Edge-ring 缺陷调查和 Pressure 报警处置 |
| 晶圆图 | Edge-ring 与正常对照两张 320×320 PNG，文本可召回并经鉴权接口返回真实文件 |
| SPC | 120 行 15 分钟时序 CSV，包含 Lot/Wafer/Tool/Chamber、CL/UCL/LCL 和 5 个 OOC 标签 |

资产可以通过以下命令确定性重建，重建结果必须与语料中保存的 SHA-256 一致：

```powershell
conda run -n dl python scripts/generate_demo_assets.py
```

- `demo-v2`：当前冻结集，包含 8 条 SOP、Recipe、SPC、图片、FDC、过期版本、无权限和
  无答案 Case。每条显式保存 Actor Scope、预期结果类型、预期 Chunk 和失败标签。
- `semikb-intent-v1`：T9-4.3.2 已创建的 96 条半导体会话理解冻结集，Hash 为
  `01caa8a4fa2180e2dea19df3ea04da2cb80512f10bf10076d47c42dbce53b228`。覆盖 SOP 当前/历史版本、
  Recipe 查询/影响分析、FDC 查询/解释、任务与非任务、反馈、控制、混合输入、最多 3 个受控任务、
  情绪干扰、指代、省略、槽位纠正、取消、中英文实体、越权写操作和 OOD。每条保存期望交互模式、

评估运行保存 `dataset_version`、组件配置、Trace ID、Recall@5 和 MRR。更换 Embedding、切分或
Reranker 时必须新增数据集/配置版本，不能覆盖基线。

`semikb-intent-v1/v2` 只从合成半导体场景和人工复核、脱敏后的失败 Trace 构建，不直接保存生产对话。版本发布后
同样使用不可变 Hash；新增真实失败样本必须发布新版本或按既定版本治理流程生成后继快照。

公开资料接入时，必须记录来源 URL、许可、抓取时间、文档版本、适用范围与版权限制。Web 搜索
得到的临时证据只可用于本轮回答，不进入冻结数据集。
