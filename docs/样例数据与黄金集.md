# 样例数据与黄金集

`data/fixtures/demo_corpus.json` 完全由项目构造，内容不包含真实 Fab、客户、Recipe 参数或
生产数据。它覆盖：

| 类型 | 目的 |
| --- | --- |
| SOP R1（过期）与 R2（现行） | 验证版本过滤不会返回历史版 |
| Edge-ring 缺陷 Case 与晶圆图图注 | 验证“文本 -> 图注/检测结果 -> 真实图片”检索 |
| Pressure FDC 规则 | 验证故障处置类检索 |

`data/golden_sets/demo_v1.json` 是冻结的三条可公开展示黄金问题。每条包含预期 Chunk、可用
Scope 和失败标签。评估运行会保存 `dataset_version`、组件配置、Trace ID、Recall@5 和 MRR；
更换 Embedding、切分或 Reranker 时必须新增数据集/配置版本，不能覆盖基线。

公开资料接入时，必须记录来源 URL、许可、抓取时间、文档版本、适用范围与版权限制。Web 搜索
得到的临时证据只可用于本轮回答，不进入该数据集。
