# 样例数据与黄金集

`data/fixtures/demo_corpus.json` 完全由项目构造，内容不包含真实 Fab、客户、Recipe 参数或
生产数据。它覆盖：

| 类型 | 目的 |
| --- | --- |
| SOP R1（过期）与 R2（现行） | 验证版本过滤不会返回历史版 |
| Edge-ring 缺陷 Case 与晶圆图图注 | 验证图文引用链路；当前仅返回运行时合成 SVG 预览，不代表真实图片资产已入库 |
| Pressure FDC 规则 | 验证故障处置类检索 |

`data/golden_sets/demo_v1.json` 是冻结的三条可公开展示黄金问题。每条包含预期 Chunk、可用
Scope 和失败标签。评估运行会保存 `dataset_version`、组件配置、Trace ID、Recall@5 和 MRR；
更换 Embedding、切分或 Reranker 时必须新增数据集/配置版本，不能覆盖基线。

公开资料接入时，必须记录来源 URL、许可、抓取时间、文档版本、适用范围与版权限制。Web 搜索
得到的临时证据只可用于本轮回答，不进入该数据集。

## 当前缺口（2026-08-11 审计）

当前样例只能作为部分演示基线，尚未达到 T3 完成标准：

- Recipe 仅作为 SOP/Case 元数据出现，缺少独立 Recipe 多版本文档和变更关系。
- `data/` 下没有 PNG/JPG/TIFF 等真实晶圆图文件，`object_ref.sha256` 也不是图片字节哈希。
- 缺少 SPC 时序数据及 UCL/LCL、异常标签、Tool/Chamber/Wafer 关联字段。
- 样例文档未逐条显式保存来源、许可和 `access_scope_key`，部分字段依赖代码默认值。
- `demo-v1` 只有 3 条正例，缺少 Recipe、SPC、无权限、过期证据、无答案等覆盖。

这些缺口补齐并通过专项测试前，T3 保持“部分完成”。
