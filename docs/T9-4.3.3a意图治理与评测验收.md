## 3. 运行时策略

- L0 规则和确定性 Demo 不调用意图 LLM，因此 `cards_in_prompt=0`。
- 所有未命中 L0 的复杂请求固定加载同一目录的全部 13 张 active 卡，不做关键词、Embedding 或第二次
  LLM 候选卡预筛；draft/deprecated 卡不进入 Prompt。
- 意图目录在服务启动时完成严格校验并缓存。模型只能提出结构化语义建议，最终权限、风险、槽位和
  路由仍由确定性 `RoutePolicy` 决定。
- 请求台账新增可选 `understanding_audit`，保存目录版本/Hash、卡数、Token、调用来源和时延；不保存
  Prompt、卡片正文、用户正文、隐藏推理或密钥。旧 MongoDB 文档无需破坏性迁移。
- 容量门禁为 active 卡 24、Prompt Token 12000、P95 5000 ms。超限只告警，不自动改变全量卡策略。
