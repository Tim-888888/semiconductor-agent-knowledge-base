# T9-4 端到端验收报告

## 1. 结论

2026-08-23，SemiAtlas 在 4 vCPU、8 GiB 的阿里云测试 ECS 完成 T9-4.1~T9-4.9。最终一键验收的
`final_demo`、`security`、`offline_bundle`、`storage_invariants`、`worker` 和 `health` 六类总门禁
全部通过，存储比较无差异。公网桌面和 `390 x 844` 移动端实际点击、截图及已登录工作台 Console
0 error/warning 通过。

因此，T9-4 与 T9 已达到**可重复的面试 Demo 标准**。该结论不代表正式生产发布：HTTP、公网 SSH
密码登录和 MongoDB 单节点仍是明确阻塞项。

## 7. 质量边界

最终 9 场景是演示回归门禁，不替代冻结离线评估。当前有效 v2 holdout 仍为 5/6；已知失败是无证据
问题误命中表格画像，已打开数据没有被用于继续调参。离线评估页保留的历史 Full 运行也可能显示低于
1.0 的指标，这些是可观测缺口，不应包装成全部准确。

当前正式生产阻塞项：

1. 公网入口仍为 HTTP，需配置域名、HTTPS、证书续期和 HSTS。
2. SSH 22 因测试期多地点办公仍对公网开放并允许密码登录，需改为密钥登录、限制来源或受控运维通道。
3. MongoDB 仍是单节点，需升级副本集并验证事务、故障转移、备份与恢复。
4. 4 vCPU/8 GiB 只通过当前有界 Demo 负载，不代表生产 SLA；首 Delta P95 仍有优化空间。
