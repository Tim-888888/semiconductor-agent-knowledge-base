# T9-4.11 意图语义接地与知识证据降级修复计划

> 状态：已于 2026-08-28 完成。验收结果见
> `docs/T9-4.11意图语义接地与知识证据降级验收.md`。

## 1. 修复目标

本阶段修复两类同源问题：一般知识问题被错误规划为制造数据任务并触发无关澄清；知识查询只能依赖内部
语料，内部证据不足时缺少受治理的降级闭环。修复必须面向未知问题泛化，禁止为已知问题、演示问句或
冻结评测答案建立专用分支。

## 2. 固定边界

- L0 只处理固定命令、取消、安全和权限，不使用业务关键词直接决定知识、数据或调查路由。
- 一次结构化 LLM 仍负责主要语义理解；服务端负责原文接地、任务一致性、槽位和执行边界。
- 明显语义冲突由服务端修正；边界冲突最多允许一次结构化修复调用，仍不确定时自然澄清。
- 冻结 `semikb-intent-v1/v2/v3` 内容和 Hash 不变；旧 MongoDB、Checkpoint 和 Trace 可读。
- 不新增基础设施、模型或 API Key；外部 Web 证据不写入受控知识库。
- 所有在线开发验证和部署只使用香港 ECS `47.76.218.205`，深圳 ECS 不得连接或修改。

## 3. 串行任务

### T9-4.11.1 语义理解 v2 与任务接地

新增时间属性、期望输出、知识治理范围、任务形态、分组维度和原文依据。每个非直接会话任务必须引用
当前用户消息或合法上下文消息中的真实片段。首轮完整问题固定使用用户原文；省略式追问重写必须保留
已确认实体并拒绝意图目录名、系统字段和提示词污染。

### T9-4.11.2 条件槽位与 RoutePolicy

新增版本化意图目录 v5。按概念解释、指定实体查询、聚合排行、事件列表、趋势分析和根因调查分别计算
必填条件。`group_by=product/tool/lot` 表示返回维度，不作为缺失输入。条件槽位修复不得改变历史回顾、
普通聊天、拒绝、澄清恢复、组合任务和受控写操作边界。

### T9-4.11.3 证据充分性与 Web 降级

内部检索后执行确定性证据检查；只有边界 Case 才调用现有 LLM 做结构化 answerability 判断。输出
`sufficient/partial/insufficient`、稳定原因码、覆盖信息和审计来源。公开通用知识不足时允许一次受控
Web 降级；内部受控知识禁止外部替代；混合知识中内部证据优先。

### T9-4.11.4 冻结评测与非回归

新增至少 120 条未见评测数据，以最小差异对验证概念、动态数据和调查意图。测试模型非法输出、无依据
任务、错误 standalone query、Provider 失败、空召回、低分召回、矛盾证据、Web 失败和旧数据恢复。
既有 v1/v2/v3、澄清状态机、图片、SSE、Trace、任务中心和离线评估必须全部非回归。

### T9-4.11.5 香港 ECS 验收

部署前后记录六个受保护数据容器 ID、跨存储指纹、API/Worker/Web 健康和监听端口。只重建应用容器，
通过公网工作台验证一般检测流程、动态良率排行、一般良率原因、指定产品调查、内部 Recipe 和显式公开
资料六类场景；检查真实 SSE、Trace、证据来源标记、刷新恢复、桌面和移动视口以及 Console。

## 4. 回滚与迁移

新契约字段保持可选默认值，MongoDB 不执行破坏性迁移；Milvus 和 MinIO 不变。意图目录 v4 保留，
新增语义接地和证据降级开关。回滚只恢复 v4 目录并关闭新开关，不删除新 Trace 或历史请求。

## 5. 完成定义

只有本地全量门禁、冻结集指标、香港 ECS 存储不变量、真实公网 API/SSE、桌面和移动点击全部通过，才能
标记 T9-4.11 完成。完成后更新分阶段计划、测试计划、开发记录和独立验收报告，并使用英文 Git commit。
