# T9-4.4.6a 来源与生命周期契约及迁移验收

## 1. 验收结论

T9-4.4.6a 已完成。项目已冻结版本化来源登记、文档生命周期、知识文档清单、下架/恢复请求、跨存储
影响计数和补偿状态契约，并在目标 ECS 对 MongoDB 执行了只新增索引的版本化迁移。

本结论不代表下架/恢复功能已经可用。管理员 API、RBAC、MongoDB 运行时阻断、Milvus 精确清理、
MinIO 恢复、补偿 Worker 和知识文档页面均属于 T9-4.4.6b。

## 2. 冻结契约

- `SourceManifest` 契约版本：`semikb-source-manifest-v1`。
- 来源唯一版本：`(source_id, manifest_version)`；同版本同内容幂等，同版本不同内容拒绝覆盖。
- 来源属性：URL/DOI/仓库、抓取时间、SHA-256、真实/合成/派生、许可状态、再分发策略和数据集版本。
- 入库策略：文档 Chunk、表格数据字典/画像/分析工具、图片 `image_text`、仅参考四种模式。
- 大型表格门禁：`raw_row_vectorization` 只能为 `false`，原始行不进入 Milvus。
- 生命周期：兼容新增 `withdrawn`；旧记录缺少来源关联字段时仍可反序列化。
- 操作契约：下架/恢复请求、前后状态、影响 Revision/Chunk/图片/表格/向量计数、补偿状态和审计关联。
- TypeScript 与 Python 枚举、字段同步；冻结 Schema 位于
  `docs/evidence/t9-4-4-6a/source-governance-contract-v1.schema.json`。

现有合成语料基线 Manifest 为 `data/source_manifests/semikb-demo-corpus-v1.json`，其本地 Hash Scope
已验证。真实公开来源将在 T9-4.4.6c 创建独立 Manifest，不覆盖该文件。

## 3. MongoDB 迁移

迁移版本为 `t9-4.4.6a-source-governance-v1`，目标仅包含：

| Collection | 新增索引 | 作用 |
| --- | --- | --- |
| `document_catalog` | `lifecycle_approval_created_at` | 生命周期、审批和时间过滤 |
| `document_catalog` | `source_manifest_ref` | 文档 revision 追溯来源版本 |
| `source_manifests` | `source_id_manifest_version`（唯一） | 来源版本不可变 |
| `source_manifests` | `status_created_at` | 状态和时间查询 |
| `source_manifests` | `source_hash` | Hash 追溯 |
| `audit_events` | `resource_created_at` | 按资源定位生命周期审计 |

迁移默认 dry-run，保存前置快照，只创建缺失且定义完全匹配的批准索引，不删除或替换现有索引。遇到
未知同名索引或定义冲突会拒绝执行；应用失败会恢复迁移前状态。显式回滚在 `source_manifests` 已有业务
记录时拒绝删除集合。历史 T2-G4 和 T6 迁移各自使用冻结索引集合，不会吸收本阶段变更。
