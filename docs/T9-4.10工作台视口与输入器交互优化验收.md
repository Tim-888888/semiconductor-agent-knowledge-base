# T9-4.10 工作台视口与输入器交互优化验收

## 1. 结论

2026-08-23，工作台在等待澄清时的视口溢出与输入框缩放交互已修复，并在本地构建、目标 ECS、
桌面浏览器和 `390 x 844` 移动视口完成验收。本阶段只修改前端布局和输入器交互，不改变线程状态、
澄清状态机、API、存储契约、检索或工具执行。

## 2. 实现边界

1. `main-area-workbench` 只约束工程师工作台，使用动态视口并把剩余空间交给工作区；其他运营页面不受影响。
2. `conversation-panel` 继续按“线程标题、澄清状态、消息区、输入区”排列，只有消息区滚动。
3. 澄清响应不再设置重复的绿色通知；黄色栏仍严格由 `waiting_for_clarification` 控制，恢复、取消或换题后消失。
4. textarea 的浏览器原生 `resize` 被禁用，改用可访问的展开/收起图标按钮；展开不会清空文本或改变发送语义。
5. `<=920px` 时工作区与证据区保持单列可访问；`<=700px` 时扣除 58px 移动导航高度。
