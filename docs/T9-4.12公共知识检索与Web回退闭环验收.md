# T9-4.12 公共知识检索与 Web 回退闭环验收

## 1. 验收结论

T9-4.12 已完成。公开通用知识请求不再把 Reranker 选中的低分 Chunk 直接当作可回答证据；系统先执行
回答可用性门禁，再决定使用内部入库知识还是 Web。内部 Chunk 全部不合格时，它们仍保留在 Trace，
但不会进入答案证据账本，也不会用于拼凑结论。

Web 返回有效资料时，公开问题使用自然回答和可点击来源链接，不显示“已知事实/未知项/下一步”的结构化
调查卡。内部 SOP/Recipe 等受控问题仍保持原有内部检索、证据账本和结构化调查卡，不允许 Web 覆盖。

实现已部署到香港 ECS。只重建 API、Worker、Web，MongoDB、Milvus、双 MinIO、etcd 和 Redis 容器
ID 均未改变；深圳 ECS 已释放，本阶段没有连接或修改深圳环境。

## 2. 根因与修复

### 2.1 根因

1. 动态截断主要依据候选之间的相对分差。候选整体都很差时，仍可能从一组低价值结果中选出“相对最好”
   的若干 Chunk。
2. Reranker 的“入选”同时被当成“可用于回答”，Trace 审计集合和最终答案证据集合没有彻底分开。
3. `public_general` 复用了内部调查模板，Web 资料即使返回，也可能被内部证据边界和固定结构压缩掉。
4. Web MCP 响应存在结构化字段、JSON 文本和普通文本链接等多种形态，旧逻辑主要依赖正文 URL 提取，
   Provider 成功不等于能够形成可引用资料。

### 2.2 回答可用性门禁

每个候选在 RRF、Rerank 和动态截断后增加独立 `answer_eligible` 判定。公开知识默认同时考虑：

- 绝对相关度下限；
- 相对最佳候选的得分比例；
- 候选间的绝对差值和断崖位置；
- 问题关键术语在 Chunk 中的覆盖度；
- 证据充分性对问题范围的覆盖结论。

候选可以是 `rerank_selected=true`，同时是 `answer_eligible=false`。前者表示保留在候选集和 Trace 中，
后者表示不得进入答案。内部受控范围保留兼容策略，避免公开知识阈值误伤低分但有效的内部 SOP。

这些阈值是冻结校准集得到的默认值，不是跨领域永久常数；后续只能通过新校准集调整，不能为某个已知
问句或文档写特殊规则。

### 2.3 Web 回退闭环

公开知识没有可回答 Chunk 时进入 Web 回退：

1. 网关调用阿里云 Web Search MCP，并保存脱敏的查询变体、Provider 结果和数量审计。
2. 解析 MCP `structuredContent`、JSON 页面列表和普通文本链接，不再只依赖正文 URL 正则。
3. 不按域名或 URL 硬删除搜索结果；已有可信域名配置只标记 `preferred` 属性，不作为拒绝条件。
4. 首次结果为空时允许一次内容导向的查询改写重试，重试次数有上限，避免循环和无限成本。
5. 标准化结果保留标题、URL、域名和摘要，作为临时 `external` 证据参与当轮生成，不写入 MongoDB
   `document_catalog`、Milvus 或 MinIO 受控知识库。
6. Web 有结果时生成自然答案和来源链接；Provider 最终不可用或完全无结果时明确说明外部检索未完成，
   仍不得回退到低价值 Chunk 冒充答案。

“解析 MCP 结构化结果”的含义是：当 Provider 已经把搜索结果以对象数组返回时，系统直接读取标题、
链接和摘要字段；只有结构化数据不存在时才解析普通文本。这不是对 Web 内容做额外过滤。

### 2.4 展示与 Trace

- `public_general + Web`：普通对话气泡、自然答案、外部来源链接，不显示结构化调查卡。
- `internal_rag`：保留结构化调查卡、内部证据按钮和证据抽屉，不显示 Web 来源。
- Trace：同时展示召回、RRF、Rerank、动态截断、回答可用性、证据充分性和 Web 审计。
- 低价值 Chunk 标记为“仅保留在 Trace”，便于解释为什么召回到了但没有用于回答。

## 6. 已知边界

1. Web 搜索不能在第三方 Provider、网络或整个互联网均不可用时保证永远成功；系统保证的是有界重试、
   多形态解析、有效结果自然回答，以及失败时不拿低价值 Chunk 伪装成功。
2. 当前 Web 来源只服务当轮回答，不自动升级为内部受控资料，也不写入知识库。
3. HTTPS 仍是香港迁移任务的独立阻塞；当前只监听 22/80，不能把 HTTP 功能验收描述为 TLS 已完成。
4. 当前结果证明面试 Demo 和回归边界，不代表正式生产上线或跨领域统一阈值。
