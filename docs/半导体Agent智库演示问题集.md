# 半导体 Agent 智库演示问题集

## 1. 用途

这份问题集用于面试演示、版本回归和演示前彩排。它不是“所有问题都保证有答案”的宣传清单，而是把
每个问题的前置数据、预期路由、展示能力和现场通过标准固定下来，避免演示时靠临场碰运气。

状态说明：

- **当前可演示**：现有合成 SOP/Recipe/Case/FDC/SPC/晶圆图和已完成系统能力即可支持。
- **T9-4.4.6 后可演示**：必须完成真实公开语料入库和 `demo-public-v1` 验收后再使用。
- **负向控制**：预期结果是澄清、拒绝、无证据或权限阻断，不应强行生成答案。
- **运维操作**：需要管理员在任务中心或知识文档页面配合操作，不是单纯对话问题。

演示前必须确认当前部署版本、数据集版本、活动 Milvus Alias、用户角色和外部 Provider 状态。尚未入库的
真实公开资料不得用 Web 临时结果冒充内部知识库证据。

## 4. 负向、治理与运维演示

| ID | 操作或问题 | 类型 | 演示场景 | 预期结果 |
| --- | --- | --- | --- | --- |
| G01 | 在任务中心上传一份带唯一测试事实的公开 PDF，再询问该事实 | 运维操作 + `internal_rag` | 多格式入库闭环 | 任务按阶段发布；问题命中新 revision；Trace、原件和派生资产可下钻 |
| G02 | 对 G01 的 revision 执行“下架”，填写原因后再次询问同一事实 | 运维操作 + 负向控制 | 误入库污染治理 | MongoDB 先阻断；该 revision 不再被检索或访问；Milvus 清理状态和审计可见 |
| G03 | 恢复 G02 的 revision，再次询问同一事实 | 运维操作 | 可恢复治理 | 重新通过审批/有效期/权限/Hash/索引校验后恢复；问题再次命中且审计链完整 |
| G04 | 重复上传与 G01 字节完全相同的文件 | 运维操作 | Hash 去重与幂等 | 不生成重复文档/Chunk/资产；页面明确提示复用、冲突或幂等结果 |
| G05 | 上传同一 `document_id` 的 R2，并把 R1 标记为 superseded | 运维操作 + `internal_rag` | revision 版本链 | 默认问题只命中 R2；明确询问历史版本时才可返回 R1 |
| G06 | 使用普通工程师账号尝试下架文档 | 负向控制 | 管理权限 | 返回 403；文档状态和检索结果不变化；审计不包含伪造成功事件 |
| G07 | 下架后直接打开旧图片短链接或重新申请资产链接 | 负向控制 | 资产二次鉴权 | 旧链接过期或不可用；新请求因 revision 已下架而拒绝，不暴露 MinIO Key |

## 5. 推荐的 8~10 分钟面试演示顺序

1. **自然会话与记忆（约 1 分钟）**：执行 C01、C04，说明直接聊天不会无意义触发 RAG。
2. **受控知识问答（约 2 分钟）**：执行 C02、C03，打开证据抽屉和 RetrievalTrace，展示版本过滤、
   Dense/Sparse、RRF、Rerank 与动态截断。
3. **主动澄清与工具组合（约 2 分钟）**：执行 C06、C07、C08，展示槽位恢复以及文档证据和只读制造
   数据工具如何合并。
4. **文本召回真实图片（约 1 分钟）**：执行 C09，展示首图自动预览、来源、revision 和短时访问链接。
5. **真实公开语料（约 1.5 分钟，仅 T9-4.4.6 后）**：执行 P09 或 P11，说明哪些是公开真实数据、哪些
   仍是合成场景，并展示多来源引用。
6. **安全与任务不漏单（约 1 分钟）**：执行 C13，展示安全查询完成、危险写操作单独拒绝。
7. **知识运营闭环（约 1.5 分钟，仅 T9-4.4.6 后）**：提前准备 G01 文档，现场执行 G02 并重问，
   展示误入库内容如何立即退出检索；时间允许再执行 G03。

若面试时间只有 5 分钟，保留 C02、C06/C07、C09、C13 和 G02；不要临时增加未彩排的开放式问题。

## 7. 演示前检查清单

- 只使用标记为“当前可演示”或已经通过 T9-4.4.6 验收的问题。
- 记录当前 `dataset_version`、Milvus Alias、Embedding/Reranker/LLM 模型和 Parser/Chunker 版本。
- 预跑主线问题，确认 API、Worker、Web、MongoDB、Milvus、MinIO、Redis 和外部 Provider 健康。
- 使用正确 Demo 角色测试 C16/G06，不能用管理员账号冒充权限隔离成功。
- 打开浏览器开发者工具，确认 Console 无错误，SSE 是真实分段到达而非前端伪打字。
- 检查图片来自授权 MinIO 对象，旧结果无图时预览区域会清空。
- 为 Web/在线 Provider 准备降级说明；外部服务失败不能影响内部受控知识演示。
- 不把合成 SOP/Recipe/Case 描述成真实 Fab 生产数据，不把公开数据集描述成客户数据。

## 8. 失败判定

出现以下任一情况，该问题不能算演示通过：

- 答案正确但引用了过期、无权、已下架或不存在的证据。
- 直接聊天、历史回顾、澄清或拒绝无必要地调用了检索、Reranker、Tool 或 Web。
- 图片由模型临时生成，或无法回链到 `image_id/document_id/revision`。
- 大型表格被逐行切成海量 Chunk，导致检索结果是孤立行且无法解释数据范围。
- 下架只改了前端显示，实际检索或旧资产链接仍能访问内容。
- 回答把公开数据、合成场景或模型推断说成真实 Fab 已确认事实。
- 页面展示完成，但 MongoDB、Milvus、MinIO、Trace、Job/Event 不能对账。
