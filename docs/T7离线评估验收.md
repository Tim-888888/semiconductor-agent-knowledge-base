# T7 离线评估验收

## 验收范围

- MongoDB 保存不可变黄金集和评估运行，Redis 只作 Celery broker/result。
- API 异步创建，Worker 原子认领、失败重试；运行可跨进程恢复。
- Dense、Hybrid、Reranked、Full 四档逐级比较。
- Case 可下钻到 Trace、候选路由、分数、截断、缺失证据和失败标签。
- 评估 API 仅 `knowledge_admin`/`admin` 可访问。
- 评估管理员通过运行/Case 专用接口读取关联 Trace；通用 Trace 列表仍保持用户隔离。

## 复现命令

先用 `DEMO_MODE=false` 启动本项目 Celery `solo` Worker，然后执行：

```powershell
python scripts/verify_t7_evaluation.py --timeout 900 --replace-acceptance-runs
```

启动 `DEMO_MODE=false` 的 API 和 Worker 后执行：

```powershell
python scripts/verify_t7_api.py --base-url http://127.0.0.1:8010 --timeout 300
```

`--replace-acceptance-runs` 只替换 `requested_by=t7_live_acceptance` 且数据集为 `t5-live-v1`
的旧验收运行，并只删除这些运行明确引用的 Trace，不触碰用户流量或其他项目数据。
