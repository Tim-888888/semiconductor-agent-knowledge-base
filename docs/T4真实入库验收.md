验收日期：2026-08-11。范围仅包含 T4 原始文档入库、状态治理和真实存储，不提前宣称 T5

## 验收对象

| 组件 | T4 职责 | 验收结果 |
| --- | --- | --- |
| MongoDB | Job、Event、Document、Chunk、Image、Release 业务状态 | 通过 |
| MinIO | 原件、解析 Markdown、真实图片 | 通过 |
| BGE-M3 | 1024 维 Dense 与 Sparse lexical weights | 通过 |
| Milvus | staged/published 向量、读回校验、活动 Alias | 通过 |
| Redis/Celery | 真实模式异步投递边界、任务注册、失败可重试 | 独立 Worker 经真实 Redis 消费通过 |

## 实现闭环

```text
API submit
  -> MinIO source + SHA-256
  -> MongoDB atomic idempotent Job + replay payload
  -> Celery Worker
  -> Markdown direct parse or MinerU adapter
  -> MinIO parsed Markdown and referenced images
  -> semantic chunks + image_text chunks + quality gate
  -> BGE-M3 Dense/Sparse batches with finite-value checks
  -> MongoDB and Milvus staged writes
  -> Milvus ID/lifecycle read-back
  -> MongoDB and Milvus published
  -> active Alias + index release
  -> supersede old revision

any failure
  -> safe Job error event
  -> quarantine current revision
  -> delete vectors by exact chunk_id
  -> keep previously active release available
  -> replay from persisted source on retry
```

## 真实结果

验收脚本使用两条独立的 CC0 合成资料：

- `T4-CASE-ETCH-03/R1`：4 个 Chunk、1 张真实合成晶圆图、首次发布成功。
- `T4-RETRY-SOP-ETCH-03/R1`：1 个 Chunk，首次注入 Embedding 失败，跨服务实例第 2 次发布成功。

## Celery 独立 Worker 验收

第一次启动真实 Worker 时，任务进入 Redis 后保持 `queued`。审计确认 Celery App 没有导入
`semikb.workers.tasks`，Worker 因而无法注册 `semikb.ingestion.process`。修复方式是在 App 的
`include` 中显式注册任务模块，并增加自动测试验证两个入库任务都存在于任务注册表。

修复后使用 `DEMO_MODE=false` 和 `--pool=solo` 启动独立 Worker，提交临时合成资料
`T4-CELERY-SOP-ETCH-04/R1`。真实结果为：

```json
{
  "status": "passed",
  "attempt": 2,
  "events": 9,
  "milvus_rows": 1,
  "milvus_lifecycle": "published"
}
```

该任务确实经过 Redis broker，由另一个 Worker 进程加载 BGE-M3 并写入三类存储。验收后已
精确删除该临时 Job、Event、Document、Chunk 和两个 MinIO 对象，并停止 Worker；没有清空队列、
删除 Collection 或修改服务配置。主验收的两条合成资料保持不变。

## v1 到 v2

第一次真实写入暴露出 `semikb_chunks_v1` 没有 `lifecycle` 字段，无法在活动 Collection 内
隔离 staged 与 published 向量。处理方式是保留 `v1`，创建带完整生命周期字段和相同
Dense/Sparse 索引契约的 `v2`，验证首批数据后切换 Alias。没有执行 Collection 删除、原地
Schema 修改或其他项目数据迁移，`v1` 中不残留本轮 T4 Chunk。
