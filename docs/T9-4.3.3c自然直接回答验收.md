# T9-4.3.3c 自然直接回答验收

## 1. 结论与边界

2026-08-14，T9-4.3.3c 已完成本地测试、ECS 增量部署、真实 MongoDB 审计和公网浏览器验收。
新请求不再产生 `history_direct`；该枚举仅保留给旧 MongoDB、Checkpoint、Trace、OpenAPI 和
TypeScript 数据反序列化。生产继续使用 B：一次结构化 LLM 看见全部活动意图卡，不使用固定或动态
Few-shot，也不调用意图示例 Embedding。

本结论只覆盖自然直接回答。T9-4.3.3d 的受控组合执行、逐任务结果和前端路由标签，以及
T9-4.3.4/T9-4.4 均未开发，T9-4 和 T9 仍未完成。

## 2. 已实现内容

1. 新增 `semikb-intent-catalog-v2`，活动卡 14 张；历史回顾和历史变换只允许
   `chat_direct/clarify`，通用域外任务由 `action.out_of_scope` 统一处理。
2. 新增冻结集路由迁移覆盖层，不修改 v1/v2/v3 原文件与 Hash；旧期望中的
   `history_direct` 在当前评测语义中映射为 `chat_direct`。
3. 新增 `DirectReplyGenerator`，分别处理普通交流、历史回顾、历史变换、反馈、控制确认、澄清和拒绝。
4. 普通交流最多使用最近 12 轮/6000 字符精确历史和 2000 字符摘要；历史回顾只接收服务端选定的
   `context_message_ids`，原文由服务端精确插入。
5. 模型逐行返回 JSON 文本单元；每个单元通过消息 ID、槽位、原因码、替代方案和历史标识符校验后，
   才发送 SSE `answer_delta`。首单元失败返回完整确定性降级，部分输出后失败追加安全结尾。
6. 澄清拆成生成节点和 `interrupt` 节点，Checkpoint 恢复不会重复调用自然回复生成器。
7. 拒绝使用普通会话气泡，不再伪装成结构化调查结果。
8. `agent_message_requests.direct_reply_audit` 保存回复类型、Provider/模型、生成模式、时延、验证单元数、
   上下文消息数、告警码和 Token 用量，不保存 Prompt、原始历史或密钥。

## 3. 开发中发现并修复的缺口

### 3.1 通用域外任务被误判为普通聊天

首次公网点击 `帮我写一首关于晚风的诗` 时，LLM 把请求误标为普通交流并直接生成了诗。修复没有增加
诗歌、笑话等主题黑名单，而是增加通用的任务结构识别，并在结构化 LLM 结果归一化后执行服务端能力
边界校验。即使 LLM 把无关的生成、建议、查询、分析或执行任务误标为 `conversation`，也不能绕过
`action.out_of_scope`。重新部署后该请求稳定进入 `refuse`，且没有 Retrieval、Tool、Web 或 Trace。

### 3.2 MongoDB 未写入直接回复审计

内存测试已有 `direct_reply_audit`，但首次真机查询发现 MongoDB 终态更新映射漏写该字段。现已在终态
更新中显式写入，在失败重试初始化时显式清空，并增加 Mongo Repository 级回归测试。真机复验中：

- 普通能力咨询：`general_chat / llm_stream`；
- 历史回顾：`history_recall / llm_stream`，`context_message_count=1`；
- 能力边界拒绝：`refusal / llm_stream`，`trace_id=null`；
- 三者均记录 Luna Provider/模型、时延、验证单元和安全用量字段。

### 3.3 API 容器重建后的 Nginx 地址刷新

只重建 API/Worker 后，现有 Nginx 可能继续使用旧 API 容器 IP，公网短暂出现 502。已按部署约定只
强制重建 Web，使 Nginx 重新解析 API；数据服务和数据卷未修改。后续应用增量部署必须按
`API/Worker -> Web -> /api/v1/live` 顺序验收。

## 5. 公网浏览器验收

在 `http://112.74.99.143/` 亲自完成以下操作：

1. 问候、身份和能力咨询自然回答；
2. 连续两次询问“我刚才说什么”，两次都引用最近一条非历史元问题，没有自引用；
3. 把历史问题简化为一句话，没有引入源消息不存在的编号或数值；
4. 缺少信息的良率调查只追问 `product/time_range/tool_or_chamber`，补齐后恢复原 LangGraph 调查；
5. 通用域外任务和 Recipe 写入请求均自然拒绝，并给出合法替代用法；
6. 刷新后消息数和最后回复完全一致；
7. 1440x900 桌面与 390x844 移动视口无重叠或横向溢出，控制台无错误。

6021 ms 完成文本，证明不是等待完整回答后一次性显示。
